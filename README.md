# _dancing jovial penguin_'s personal website

This is a quick overview on the resources I have been using to sustain the website.

## Applications

- Visual Studio Code as the code editor
- GitHub to host the source code
- Git to keep track of the version history and commits
- Krita for visual graphics
- Google Documents for my writings
- Neocities to host the website

Krita and Git are _free and open-source_ software, and the rest have been free of cost for my usage.

## Blogging

I write my blog posts on Google Documents. When I complete a work, I copy the entire document's content and paste it on a new Markdown file. In the file, I lightly edit the text to conform to Markdown syntax. To simplify the process of converting Markdown text to HTML and listing my blogs in one place, I have created [this simple tool](https://github.com/erenoguzyesil/md-to-html-blogging). Finally, I upload the generated HTML file on Neocities and delete the Markdown file as it is no longer necessary.

## Notes

While the website is mostly open-source, I do not track all my writings in the _blogs/_ directory as I upload them to Neocities. This is because I tend to upload and update my existing writings often, so I did not want to clutter the commit history with them.
